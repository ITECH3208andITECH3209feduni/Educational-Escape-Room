FedEscape – Educational Escape Room Platform

Project Description

FedEscape is an educational escape room platform designed to make learning more interactive, engaging, and collaborative.

The platform will allow teachers to create educational escape rooms containing questions, puzzles, timers, and challenges. Students will be able to join escape rooms, complete challenges, track their progress, and compete through scoring and leaderboards.

The Sprint 1 focus is to develop the frontend prototype and establish the basic structure and navigation of the application. Backend and database functionality will be implemented in future sprints.

Installation Instructions

1. Clone the Repository

git clone <repository-url>

2. Navigate to the Project

cd FedEscape

3. Pull the Latest Changes

git pull origin main

4. Open the Project

Open the project folder in Visual Studio Code or another code editor.

The current Sprint 1 frontend does not require any external packages or database configuration.

---

How to Run the Project

Option 1 – Open Directly

Navigate to:

client/index.html

Open "index.html" in a web browser.

Option 2 – Using Visual Studio Code

1. Open the project in Visual Studio Code.
2. Install the Live Server extension.
3. Right-click "client/index.html".
4. Select Open with Live Server.

The FedEscape frontend will open in the browser.
