About FedEscape

FedEscape is a web-based educational escape room system designed for Federation University. The platform enables educators from different disciplines to create engaging escape rooms containing quizzes, puzzles, and multimedia learning activities.

Students can join escape rooms online, work individually or in teams, solve challenges, and receive feedback while developing problem-solving and teamwork skills.

Platform Features

👨‍🏫 Teachers

Create educational escape rooms, manage questions, add puzzles, and monitor student progress.

🎓 Students

Join rooms using a code, solve challenges, answer questions, and complete missions.

📊 Analytics

Track student performance, completion times, scores, and learning outcomes.
